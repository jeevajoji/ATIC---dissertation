1. PURPOSE AND STATUS OF THIS DOCUMENT
--------------------------------------

This document records the work completed on the ATIC learned image-compression
project, including successful implementation work, validation results,
negative findings, technical failures, and the next experimental gate.

It is deliberately conservative. Results labelled as pilot or validation
results must not be presented as independent-test results. At the time of this
record, the frozen Beauty test sequence has not been evaluated. No valid
multi-rate BD-rate result has yet been obtained, and no state-of-the-art claim
is supported.


2. PROPOSED RESEARCH CONTRIBUTION
---------------------------------

The proposed contribution is Decoder-Synchronised Attention Distillation
(DSAD) for learned image compression.

An encoder can observe the original image and can therefore learn a strong
spatial attention map. A decoder cannot observe the original image. Directly
using the encoder attention map during decoding would either make decoding
impossible or require the map to be transmitted as additional side
information.

DSAD instead uses two maps during training:

    encoder features -> encoder-only teacher attention map

    decoded z_hat -> hyperdecoder features -> student gain map

The teacher is training-only. The deployable student map is predicted from
z_hat and decoder-side network weights. Therefore, the encoder and decoder can
independently reproduce the same gain map without transmitting a separate
attention map.

The current DSAD loss compares spatially centred log-gain maps:

    centred_log(g) = log(g) - spatial_mean(log(g))

    L_DSAD = SmoothL1(
        centred_log(student_gain),
        stop_gradient(centred_log(teacher_gain))
    )

The complete training objective is:

    L = R_y + R_z + lambda_rd * 255^2 * MSE + beta * L_DSAD

The centring operation removes global log-scale information from the
distillation target. Its purpose is to teach spatial bit reallocation rather
than allowing the student to reduce the loss by uniformly increasing or
decreasing every gain value. This does not guarantee equal actual bitrate;
actual coded-file BPP must still be measured.

The proposed novelty is therefore not merely "using attention". The intended
novelty is transferring an encoder-only spatial allocation signal into a
causal decoder-reproducible gain mechanism without sending a separate
attention map. Whether this mechanism improves compression efficiency remains
an experimental question.


3. OPERATIONAL CODEC AND TRANSFERABILITY
----------------------------------------

The project implements a real entropy-coded ATIC container rather than saving
latent tensors in an NPZ file.

The transferred .atic file contains:

    1. a versioned header;
    2. entropy-coded z bytes; and
    3. entropy-coded y bytes.

The receiver also needs:

    1. the exact trained model checkpoint;
    2. compatible ATIC decoder code and dependencies; and
    3. the .atic compressed file.

Sending z_hat alone is not sufficient. z_hat supplies hyperprior information
and generates the decoder-synchronised gain/probability parameters, but y is
the primary image latent and must also be entropy decoded.

Completed codec checks showed:

    encoder latent repeated exactly:               true
    repeated bitstreams identical:                 true
    z_hat forward versus coded stream exact:       true
    gain forward versus coded stream exact:        true
    y_hat forward versus coded stream exact:       true
    x_hat forward versus coded stream allclose:    true
    maximum x_hat absolute difference:             1.7881393432617188e-07

The very small x_hat difference is floating-point decoder arithmetic, not a
latent or bitstream mismatch.

6. CONTROLLED DSAD COMPARISON
-----------------------------

The causal DSAD comparison uses two named variants:

    Full_ATIC_NoDSAD: identical full architecture, beta = 0
    Full_ATIC_DSAD:   identical full architecture, beta > 0

The architecture, initialisation seed, dataset order, lambda_rd, optimiser,
training duration, entropy model, adaptive gain mechanism, and evaluation
method are matched. The intended causal difference is the DSAD loss weight.

The Full_ATIC_NoDSAD arm is not a plain hyperprior. It retains the complete
ATIC architecture and adaptive gain student. It is the correct control for
asking whether distillation helps the same deployable model.

11. WHERE THE EXPERIMENT FAILED
-------------------------------

The multi-rate experiment failed before it could test the DSAD compression
claim. Increasing lambda_rd gives distortion more weight, so a sufficiently
trained family of models should normally move towards higher reconstruction
quality and generally higher bitrate. Small deviations may occur, but the
observed reversals were large.

Examples include:

    Seed 123 NoDSAD:
        lambda 0.0035 -> PSNR 15.802 dB
        lambda 0.0130 -> PSNR 11.353 dB

    Seed 999 NoDSAD:
        lambda 0.0067 -> PSNR 12.543 dB
        lambda 0.0130 -> PSNR 8.605 dB

Because the NoDSAD control failed too, non-monotonicity cannot be attributed
only to DSAD. The BD-rate implementation correctly rejected these curves.
Forcing a polynomial through them or deleting inconvenient points would be
scientifically invalid.

The main confirmed weaknesses in the completed protocol were:

    1. Each model trained for only 30 epochs.
    2. The frozen training split has 360 images and batch size was 4.
    3. This gives 90 updates per epoch, or only 2,700 updates per model.
    4. The main learning rate remained fixed at 1e-4.
    5. No learning-rate scheduler was used.
    6. The final epoch was evaluated even if an earlier validation checkpoint
       had a better RD objective.

Additional architectural suspects, not yet proven as causes, are:

    1. Spatial Attention Gate BatchNorm with batch size 4 and small deep
       feature maps, which may produce unstable running statistics.
    2. The adaptive gain mechanism, which may make rate control harder.
    3. The online moving teacher, which may add instability to the DSAD arm
       but cannot explain failure of the NoDSAD control.

These causes must be isolated rather than changed simultaneously.


12. OTHER TECHNICAL FAILURES AND RESOLUTIONS
--------------------------------------------

12.1 Model-state hashing crash

The first two-GPU beta screen stopped before training with:

    RuntimeError:
    self.dim() cannot be 0 to view Long as Byte (different element sizes)

Cause:

    hash_model_state attempted to reinterpret a scalar integer state buffer
    using tensor.view(torch.uint8).

Resolution:

    Scalar and non-floating model-state buffers were serialised safely before
    hashing. The fix was committed as:

        9b1a41d - Fix scalar buffers in model state hashing

The calibration was then restarted successfully.

12.2 NVML mismatch

nvidia-smi failed with:

    Failed to initialize NVML: Driver/library version mismatch

Resolution:

    Direct PyTorch CUDA tests verified both permitted A6000 GPUs independently.
    NVML monitoring remained unavailable, but CUDA training was operational.

12.3 Framework warnings

Warnings were observed for:

    1. torch.meshgrid not explicitly receiving indexing;
    2. torchvision's deprecated pretrained argument; and
    3. NVML initialisation.

These warnings did not terminate training or explain the multi-rate control
failure. They should nevertheless be cleaned before a final reproducibility
release.


13. BASELINE-RESCUE IMPLEMENTATION
----------------------------------

The training protocol was revised and committed to branch final:

    c463640 - Stabilize RD training and gate control curves

The complete PyTorch/CompressAI continuous-integration workflow passed.

The changes are:

    1. deterministic cosine learning-rate decay;
    2. separate configurable minimum main and auxiliary learning rates;
    3. best validation-RD checkpoint restoration before entropy-table update
       and actual-bitstream evaluation;
    4. checkpoint selection metadata stored for every run;
    5. checkpoint eligibility begins only after the DSAD beta warm-up/ramp for
       paired causal studies;
    6. learning rate and checkpoint-selection state logged each epoch;
    7. a validation-only four-point monotonicity gate;
    8. explicit rejection of unlocked test studies by the gate; and
    9. epoch-by-epoch reconstruction previews retained.

The first rescue experiment was deliberately control-only:

    variant:       Full_ATIC_NoDSAD
    seed:          42
    lambdas:       0.0018, 0.0035, 0.0067, 0.013
    epochs:        120
    batch size:    4
    main LR:       1e-4 -> 1e-6 cosine decay
    auxiliary LR:  1e-3 -> 1e-5 cosine decay
    checkpoint:    lowest eligible validation RD loss
    test sequence: locked

The DSAD beta argument remains 8 only to define the checkpoint-eligibility
window that will later be shared by the paired beta = 8 experiment.
Full_ATIC_NoDSAD still trains with effective beta = 0.

Gate condition:

    At least four validation points must exist, and both actual BPP and PSNR
    must be non-decreasing as lambda_rd increases.

Baseline-rescue results:

    lambda   selected   estimated   payload     actual      PSNR
             epoch     BPP         BPP         BPP         (dB)
    ----------------------------------------------------------------
    0.0018      112     0.078975    0.073781    0.077688    16.156
    0.0035       88     0.430875    0.388118    0.392025    16.622
    0.0067       52     0.375503    0.329277    0.333183    16.786
    0.0130       70     0.987376    0.843028    0.846934    16.710

The final validation RD loss was above the selected best checkpoint by:

    lambda 0.0018:  +0.25%
    lambda 0.0035: +13.25%
    lambda 0.0067:  +6.91%
    lambda 0.0130:  +4.33%

This confirmed that final-epoch evaluation had been unsafe and that
validation checkpoint restoration was necessary.

The longer scheduled training substantially narrowed the PSNR range to
16.156-16.786 dB and removed the earlier catastrophic quality collapses.
However, the gate still failed:

    actual BPP monotonic: false
    PSNR monotonic:       false
    overall gate:         fail

The lambda = 0.0035 model was dominated by lambda = 0.0067: the latter used
fewer actual bits and produced higher PSNR. The lambda = 0.013 model used
substantially more bits but lost 0.076 dB relative to lambda = 0.0067.

Rate-accounting diagnosis:

    1. The 0.0035-to-0.0067 reversal appeared in both estimated and actual
       BPP, so the entropy coder did not create the incorrect ordering.
    2. Header BPP was constant at 0.003906 for every rate point.
    3. The y stream dominated coded rate; z BPP remained approximately
       0.0066-0.0119.
    4. Payload BPP was below estimated BPP at every rate point. The
       payload-minus-estimated gaps were -0.005194, -0.042757, -0.046227,
       and -0.144349 BPP as lambda increased.
    5. The increasing calibration gap should be improved later, but it does
       not explain the non-monotonic ordering because estimated and actual
       rates agree on that ordering.


14. DECISION AFTER THE BASELINE-RESCUE RUN
------------------------------------------

The control gate failed. Therefore:

    1. no further DSAD seed or Beauty test run is permitted yet;
    2. the next controlled experiment disables adaptive gain while retaining
       SAG, CBAM, hyperprior, data, seed, scheduler, training duration, and
       checkpoint-selection window;
    3. if No_AdaptiveQuant becomes monotonic, adaptive gain is identified as
       the main rate-control failure;
    4. if No_AdaptiveQuant also fails, the next isolated suspect is SAG
       BatchNorm, followed by a plain hyperprior sanity baseline;
    5. only after a monotonic control is established can the matched DSAD arm
       and validation BD-rate study resume.


15. CLAIMS CURRENTLY SUPPORTED
------------------------------

The dissertation may currently state that:

    1. a decoder-synchronised attention distillation mechanism was designed
       and implemented;
    2. the student gain map is reproducible from decoded z_hat and shared
       decoder weights, with no separately transmitted attention map;
    3. the encoder-only teacher is detached from the DSAD target path and is
       not required by the operational decoder;
    4. real entropy-coded bitstreams and actual complete-file BPP were used;
    5. deterministic forward/stream equivalence was verified;
    6. a frozen sequence-disjoint validation protocol was established;
    7. beta = 8 produced encouraging single-rate validation improvements in
       PSNR and LPIPS across three seeds; and
    8. the multi-rate experiment revealed an unstable baseline and therefore
       invalidated BD-rate calculation; and
    9. longer scheduled training and best-checkpoint restoration reduced the
       instability but did not restore monotonic rate control.

The negative result is useful: it prevented a misleading claim based on a
single rate point and identified baseline convergence as a prerequisite for a
valid DSAD evaluation.


16. CLAIMS NOT CURRENTLY SUPPORTED
----------------------------------

The dissertation must not yet claim that:

    1. DSAD reduces BD-rate;
    2. DSAD improves compression efficiency;
    3. DSAD beats a state-of-the-art codec;
    4. the method generalises to independent test data;
    5. beta = 8 is statistically optimal;
    6. DSAD improvements are statistically significant;
    7. the adaptive gain architecture is stable; or
    8. the complete method is publication-ready.

These claims require a monotonic baseline, matched multi-rate curves, multiple
seeds, independent test evaluation, and comparison with strong external
baselines.

18. THESIS-READY INTERIM RESULTS PARAGRAPH
------------------------------------------

A decoder-synchronised attention distillation mechanism was implemented to
transfer an encoder-derived spatial importance signal into a deployable
decoder-side gain predictor. Unlike an explicitly transmitted attention map,
the proposed student is generated from the decoded hyperlatent and shared
decoder weights. Exact equality was observed for the repeated bitstream,
decoded hyperlatent, gain map, and primary latent, while the final
reconstruction agreed within a maximum floating-point difference of
1.79 x 10^-7. A sequence-disjoint UVG-derived protocol was frozen using
Bosphorus, HoneyBee, and YachtRide for training, ShakeNDry for validation, and
Beauty as a locked independent test sequence. In a three-seed validation
experiment at lambda_rd = 0.0067, beta = 8 improved PSNR and LPIPS in all
three seeds, with mean changes of +0.977 dB and -0.0586 respectively.
However, actual BPP increased by a mean of 0.193, so this single-rate result
did not establish improved compression efficiency. A subsequent four-rate
study produced non-monotonic RD points for both the distilled model and its
identical-backbone control, invalidating BD-rate calculation in all three
seeds. The failure of the control indicated insufficient baseline
optimisation rather than a DSAD-specific conclusion. Consequently, independent
test evaluation remained locked and the training protocol was revised to use
longer optimisation, cosine learning-rate decay, and validation-RD checkpoint
selection. This rescue narrowed validation PSNR to 16.156-16.786 dB and
confirmed that final-epoch selection was unsafe, but actual BPP and PSNR
remained non-monotonic. Estimated and coded rates showed the same ordering,
while header BPP was constant, locating the remaining problem in model-level
rate control rather than container overhead or entropy-coder accounting. The
next controlled ablation therefore removes only the adaptive gain mechanism
before any further DSAD or independent-test experiment.
